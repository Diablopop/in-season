# Masters — drop cropped artwork here

One file per fruit, named exactly `{slug}.png` (or `.jpg`).

* Square crop, at least 1024px on a side. Exact dimensions do not matter — the build script normalizes to 1024×1024.
* Keep the paper. Do not remove the background or color-correct it toward white.
* Do not draw a border. The frame stroke is applied in CSS.

Slugs must match `app/public/img/fruits/192/` filenames. See ART_SOURCING.md.
